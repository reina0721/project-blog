## 访问路径与中间状态

| 操作 | 观察结果 |
| --- | --- |
| 宽屏打开主页 | 站标与导航分别贴近视口两端，头像和姓名组成居中的身份区。当前页占据首屏高度，最近文章在下滚后出现。 |
| 进入博客 | 先收到链接的按压反馈。新页面进入时页首有一道蓝色斜切，同时内容换入，斜切不盖首段正文。 |
| 博客 → 归档 → 后退 | 视口中的导航保持原位。一次桌面采样中，标记在第 43 到 150 毫秒从 x=806 移向 844；返回方向相反。旧内容与新内容分别退场和进入。 |
| 列表 → 第二篇文章 → 返回 | 仅匹配所选文章标题。文章正文和标题单独参与过渡，结束后没有遗留隐藏标题、覆盖层或临时选中标记。 |
| 归档 → 文章 → 后退 | 从年份索引进入同一个文章地址；浏览器后退回到来源归档。直接分享、刷新文章也可读。 |
| 连续打开不同文章 | 通过相邻文章链接与浏览器历史往返，最后页面和地址一致。快速连续操作后临时动效标记归零。 |
| 手机、键盘与减少动态 | 手机版将导航移到底部。在 390 × 780 的一次切换里，第 75 毫秒旧标签高度约 6.16 像素、新标签约 3.31 像素；仅新项带有当前页语义。键盘焦点可辨，减少动态时标题、斜切和位移停用，当前项的文字与强调色仍在。 |
| 禁用 JavaScript | 从首页或归档进入文章、阅读以及原生返回均可用。内容与链接来自构建产物。 |

## 四种转场对照

同一内容、同一浏览器，原型使用两倍时长，约在动作开始 150 毫秒处取样。A 的临时标题层数量为 0，B 为 1，C 为 2。C 的第二层在取样时不透明度约 0.23；D 的移动标题保持清晰，仅背景出现约 0.7–0.9 像素模糊。四种原型落定后临时层均归零。正式站选择 B，把标题连续性用于高频阅读路径。

正式站把同级导航的横向交接、首页进入博客的局部斜切和相邻文章的前后方向分别实现。读者主观偏好尚未做盲测。浏览器验证覆盖了动画是否启动、截取的对象、方向和落定状态。

## 内容与边界情况

在隔离副本里改一次座右铭，首页和关于同步变化。加入一篇 2027 年的 Markdown 后，生成了详情，首页最近文章切换为新文，博客和归档同步更新，归档依次出现 2027、2026、2025。清空文章和好友重新构建后，博客、归档和友链显示各自的空状态；旧详情从输出中移除。

长站名可以换行，缺头像时显示站名首字，缺简介时只保留身份与链接。关闭示例模式后，示例社区入口、设计参考和示例头像退出。文章样稿由每份 Markdown 单独标识。

在 1280、768、430、360、320 像素宽下验证了主页以外的五种主要视图，未发现横向溢出。用八个测试条目时，友链目录在 1907、1280、430、320 像素宽下分别显示六、四、二、一列。在 1907 像素宽下，博客、归档、正文、目录的内容宽度分别为 1100、900、795、1659 像素。生产构建包含五个栏目首页、三篇文章及 404，总计九份 HTML。

网名、座右铭和资料目前使用明确标记的示例内容。浏览器实测覆盖 Chromium；其他引擎的原生跨文档动画未逐一取样。
